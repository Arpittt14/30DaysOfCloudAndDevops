## Linux File System

Reviewed the hierarchical file system structure.

Important directories:

| Directory | Purpose                |
| --------- | ---------------------- |
| /         | Root Directory         |
| /home     | User files             |
| /etc      | Configuration files    |
| /bin      | Essential commands     |
| /usr      | User applications      |
| /var      | Logs and variable data |
| /tmp      | Temporary files        |
| /dev      | Device files           |

---

## Linux Architecture

Revised the Linux architecture layers.

```text
+----------------------+
| User Applications    |
+----------------------+
| Shell                |
+----------------------+
| System Utilities     |
+----------------------+
| Linux Kernel         |
+----------------------+
| Hardware             |
+----------------------+
```

### Responsibilities

* Hardware executes operations.
* Kernel manages system resources.
* Shell interprets user commands.
* User Applications provide software functionality.

---

## Linux vs Unix

### Linux

* Open Source
* Free to use
* Community developed
* Widely used in Cloud Computing

### Unix

* Mostly Proprietary
* Commercial licensing
* Enterprise operating systems
* Vendor maintained

---

## Process States

Reviewed the lifecycle of Linux processes.

| State        | Description                           |
| ------------ | ------------------------------------- |
| Running (R)  | Currently executing                   |
| Sleeping (S) | Waiting for an event                  |
| Waiting (D)  | Waiting for I/O operations            |
| Stopped (T)  | Execution paused                      |
| Zombie (Z)   | Process finished but awaiting cleanup |
